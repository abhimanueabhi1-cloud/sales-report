# sales-report
Power BI Sales Report — Interactive dashboard and data model built using Power BI and Power Query for analyzing sales performance, trends, and key metrics.
Sales Report Dashboard (Power BI + Power Query)

This project showcases a dynamic Sales Report developed in Power BI, leveraging Power Query for data transformation and modeling.

🔍 Overview

The dashboard provides a comprehensive view of sales performance, helping users track:

Total sales and revenue trends

Top-performing products and regions

Customer segmentation and profitability

Monthly and yearly sales comparisons

⚙️ Tools & Technologies

Power BI — for visualization and reporting

Power Query — for data cleaning and transformation


📈 Features

Interactive filters and slicers for dynamic analysis

Automated refresh and data modeling through Power Query

Visual insights into key business metrics and KPIs

📁 Contents

.pbix file — Power BI report

Data/ — sample dataset (optional)

Documentation/ — setup guide and screenshots

🚀 How to Use

Download or clone the repository.

Open the .pbix file in Power BI Desktop.

Refresh data connections if needed.
